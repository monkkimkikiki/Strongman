식사 추가

최근 먹은 음식 (누르면 오늘 식사에 바로 추가돼요)
    양
    1

    음식을 고르면 1인분 평균값으로 칼로리와 단백질이 자동 계산돼요. 브랜드나 조리법에 따라 달라서 대략치예요. 직접 고쳐도 돼요. 직접 입력한 음식은 ‘내 음식’으로 저장돼 다음부터 검색에 나와요. 별(☆)을 눌러 즐겨찾기에 넣으면 이름 칸을 누를 때 먼저 보여요.

    AI 코치 연결

    Groq 무료 API를 연결하면 운동 기록을 바탕으로 질문 답변과 운동 총평을 받을 수 있어요. 운동 기록은 평소처럼 기기에 저장되고, AI 요청을 보낼 때 요약된 기록만 Groq로 전송됩니다.

    API 키를 저장하면 AI 코치를 사용할 수 있어요.

    키는 앱 내부의 Android Keystore로 암호화해 이 기기에만 저장합니다. 무료 이용량과 모델 제한은 Groq 계정별로 달라질 수 있어요.

    목표

    저장 위치

    운동·식단 분석 파일 내보내기

    주간·월간·전체 기록을 JSON 파일로 저장해 ChatGPT에 첨부하면 운동 진행, 부위별 운동량, 식단, 체중 변화를 종합 분석할 수 있어요.

    주간·월간은 현재 선택된 날짜가 포함된 기간을 기준으로 내보냅니다.

    설정 백업 · 불러오기

    루틴, 즐겨찾기, 내 음식·내 운동, 운동별 휴식, 목표 설정을 글자로 복사해 두었다가 새로 설치한 앱이나 다른 기기에 붙여넣어 불러올 수 있어요. 메모 앱이나 카카오톡 ‘나와의 채팅’에 붙여 두면 편해요.
