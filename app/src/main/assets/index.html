부위별 상세

완료 체크한 세트만 집계하오. 세트 시간이 30~60초 범위를 벗어나면 표시하오. 근비대에 흔히 쓰는 기준이라 참고용으로만 보시오.

체중

식사 추가

최근 먹은 음식 (누르면 오늘 식사에 바로 추가되오)
    양
    1

    음식을 고르면 1인분 평균값으로 칼로리와 단백질이 자동 계산되오. 브랜드나 조리법에 따라 달라서 대략치이오. 직접 고쳐도 되오. 직접 입력한 음식은 ‘내 음식’으로 저장돼 다음부터 검색에 나오. 별(☆)을 눌러 즐겨찾기에 넣으면 이름 칸을 누를 때 먼저 보이오.

    식품 가성비 비교

    제품 가격과 영양정보를 직접 적어 두면 단백질 가성비를 계산해 비교하오. 가격은 입력한 날짜와 함께 저장되며 실시간 가격이 아니오. 계산은 앱이 하오.

    AI 코치 연결 (Gemini)

    Google Gemini 무료 API를 연결하면 질문 답변, 세트마다 바로 해 주는 한마디 코칭, 운동 총평을 받을 수 있소. 코치가 필요한 기록만 골라 조회하고, 그 내용만 Google로 전송되오. 이름이나 이메일은 보내지 않소.

    API 키를 저장하면 AI 코치를 사용할 수 있소.

    키는 앱 내부의 Android Keystore로 암호화해 이 기기에만 저장하오. 한도를 넘으면 유료로 넘어가지 않고 요청이 멈추오. 무료 등급은 Google이 입력 내용을 서비스 개선에 쓸 수 있다고 알려져 있으니 약관을 확인하시오. 모델별 무료 한도는 Google AI Studio에서 볼 수 있소.

    목표

    저장 위치

    운동·식단 분석 파일 내보내기

    주간·월간·전체 기록을 JSON 파일로 저장해 ChatGPT에 첨부하면 운동 진행, 부위별 운동량, 식단, 체중 변화를 종합 분석할 수 있소.

    주간·월간은 현재 선택된 날짜가 포함된 기간을 기준으로 내보내오.

    설정 백업 · 불러오기

    루틴, 즐겨찾기, 내 음식·내 운동, 운동별 휴식, 목표 설정을 글자로 복사해 두었다가 새로 설치한 앱이나 다른 기기에 붙여넣어 불러올 수 있소. 메모 앱이나 카카오톡 ‘나와의 채팅’에 붙여 두면 편하오.
