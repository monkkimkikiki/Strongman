    운동·식단 분석 파일 내보내기

    주간·월간·전체 기록을 JSON 파일로 저장해 ChatGPT에 첨부하면 운동 진행, 부위별 운동량, 식단, 체중 변화를 종합 분석할 수 있어요.

    주간·월간은 현재 선택된 날짜가 포함된 기간을 기준으로 내보냅니다.

    설정 백업 · 불러오기

    루틴, 즐겨찾기, 내 음식·내 운동, 운동별 휴식, 목표 설정을 글자로 복사해 두었다가 새로 설치한 앱이나 다른 기기에 붙여넣어 불러올 수 있어요. 메모 앱이나 카카오톡 ‘나와의 채팅’에 붙여 두면 편해요.

    운동·식단 분석 파일 내보내기

    선택한 기간의 운동 세트·중량·횟수·운동량, 식단 칼로리·단백질, 체중, 루틴과 기간별 요약을 JSON 파일로 저장합니다. 저장한 파일을 ChatGPT에 첨부하면 상세 분석과 다음 운동 조언을 받을 수 있어요.

    주간·월간은 현재 선택된 날짜가 포함된 기간을 기준으로 내보냅니다.
